# ArinPay - Digital Wallet & Fintech Platform

A modern, secure, and scalable digital wallet application built for seamless financial transactions.

## Features

### User Features
- User registration & authentication (Email + Phone)
- Secure wallet funding (Card, Bank Transfer, USSD)
- Instant money transfers (P2P)
- Virtual cards issuance
- Transaction history with filtering & export
- Real-time notifications
- Bill payments & Airtime/Data purchase(coming soon)

### Admin Features
- User & wallet management
- Transaction monitoring & fraud detection
- KYC verification dashboard
- Payment gateway management
- Analytics & reporting

### Security & Compliance
- End-to-end encryption
- JWT Authentication
- Two-Factor Authentication (2FA)
- Rate limiting & fraud prevention

## Tech Stack

### Backend
- **Java 25** + **Spring Boot 3**
- Spring Security + JWT
- Spring Data JPA + Hibernate
- MySQL(for Database) + Redis(Caching & Rate Limiting)
- Apache Kafka (Event-driven architecture)
- Docker

### Frontend
- **React 18** + Vite
- Tailwind CSS
- React Router
- Axios
